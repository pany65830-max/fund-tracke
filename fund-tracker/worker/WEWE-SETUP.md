# WeWe RSS 本机部署（微信资讯源）

微信改走本机 WeWe RSS（不再用搜狗）。WeWe 是一个开源 RSS 服务，订阅你关注的基金公司公众号。

## 1. 起服务（Docker）

项目根已有 `docker-compose.yml`：

```powershell
docker compose up -d
```

- 默认地址 http://127.0.0.1:4000
- 首次打开 http://127.0.0.1:4000 用 `admin` / `admin` 登录，添加要订阅的公众号
  （华夏 / 易方达 / 国泰 / 华泰柏瑞 官方号；`feedId` 可空，适配器按名称匹配）
- 镜像 tag 如有变动，以 WeWe RSS 官方仓库为准

## 2. 让云端 Worker 也能拉到（cloudflared 隧道）

WeWe 在你本机，云端 Cloudflare 默认够不着。两种暴露方式：

- 临时：`cloudflared tunnel --url http://localhost:4000`（给一个会变的一次性地址）
- 稳定：`cloudflared tunnel login` → `cloudflared tunnel create wewe` →
  `cloudflared tunnel route dns wewe wewe.你的域名.com` → 用配置文件常驻

拿到公网地址后，填进 `config/.env`：

```
WEWE_RSS_URL=https://wewe.你的域名.com
WEWE_AUTH_CODE=<WeWe 后台的 API 鉴权码>
```

云端 Worker 每次「一键更新」会经隧道拉本机微信；拉不到则合并逻辑保留旧微信条目，不会清空。

## 3. 本机 ingest 也会读 WeWe

`scripts/ingest.ts` 默认 `WEWE_RSS_URL=http://127.0.0.1:4000`，本机定时任务跑时直接抓本地 WeWe，无需隧道。

## 4. 排错：微信资讯突然变少/为空 —— 先查 WeWe 是否掉登录

**最常见的原因不是"没发文"，而是 WeWe RSS 绑定的个人微信登录会话过期了。**
过期后 WeWe 抓不到新文章、更新失败，表现就是"微信资讯为空/像是没资讯"。

排查步骤：
1. 浏览器开 http://127.0.0.1:4000/dash ，登录 `admin/admin`。
2. 看顶部/账号区是否提示"登录失效 / 需要重新登录 / 二维码过期"。
3. 用手机微信扫码重新登录绑定账号，等后台状态恢复"正常"。
4. 重新登录后，下一次定时任务（或手动 `npm run ingest`）即可正常拉到微信。

> 注意：WeWe 的登录会话会**定期过期**（几天到几周不等，取决于微信侧策略），
> 属正常现象。以后只要发现微信源变空，第一反应就是"去 WeWe 后台重新登录"，
> 而不是怀疑没发文或代码坏了。
> 重新登录后**无需改任何代码/配置**，等下一次抓取即可。

## 5. 登录过期的根治与缓解方案（避免"定期手动重登"）

**先说结论**：WeWe RSS 抓的是**个人微信网页会话（wx.qq.com）**，建立会话必须手机扫码（人在环），
且微信服务端会主动让会话失效（几天到几周；在你用别处登录微信、或微信风控触发时失效更快）。
因此**没有任何方案能 100% 免除重登**——只要还依赖个人微信抓取，就必然偶尔要扫码。

但可以把"定期盲目重登"改成"失效时才提醒你登一次"，并显著拉长会话寿命：

### 5.1 延长会话寿命（减少失效频率）
- **容器常驻**：已配 `restart: unless-stopped`，保持 Docker 不关、不重启容器，会话掉得慢。
- **专用微信小号**：给 WeWe 单独绑一个不日常聊天、不在手机/网页另处扫码登录的微信号。
  主号在别处登录会踢掉 wewe 的会话；小号专机专用，可撑数周。
- **别在别处登网页微信**：任何时候用手机/电脑扫码登录 wx.qq.com，都会让 wewe 的会话失效。
- **(可选) 切换公众平台抓取模式**：较新镜像支持 `CRAWLER_TYPE=public_account`
  （在 docker-compose 的 `environment` 下加一行），走公众号文章检索接口，
  登录态（token）通常比个人网页会话更稳。需镜像版本支持，改前先 `docker compose images` 确认版本。

### 5.2 失效时才提醒，而不是定期盲登（推荐）
与其"每 N 天定时重登"（往往要么太早要么太晚），不如**挂一个健康检查**：
定时探一下 WeWe 是否还登录着，一旦真的失效，立刻弹个 Windows 通知/响一声，你点开扫一次码即可。

实现思路（可让 Agent 加）：
- 一个小脚本 `scripts/wewe-healthcheck.mjs`，带 `WEWE_AUTH_CODE` 调 WeWe 账号状态接口；
- 配一个 Windows 任务计划程序，每 30 分钟跑一次；失效时弹 toast 提醒；
- 这样你只在"真失效"时动手，平时完全不用管。

### 5.3 降低对微信源的依赖（治本方向）
核心几家（华夏 / 易方达 / 国泰 / 华泰柏瑞）的**官网资讯我们已经在抓**（company-web 适配器）。
微信只是补充。把官网栏目覆盖铺得更全，即使微信掉线，核心厂牌的资讯也不会空——这是最稳的长期解法。
