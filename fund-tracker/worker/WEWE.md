# 微信资讯怎么接到网站上（小白版）

你只需要搞懂一件事：

**网站自己登不了微信。** 所以要在你这台电脑上跑一个小工具（WeWe），用微信读书扫一下码，它就会把 10 个官方公众号的当天文章列成网页。同事点「一键全量更新」时，云端会来问你电脑要这份列表。

整件事分三块，**先做第 1 块就行**，后面两块可以改天再做。

```
你的电脑（WeWe）  →  一条固定网址（隧道）  →  网站一键更新
     第 1 步              第 2 步                 第 3 步
```

电脑关机时：官网公告和 ETF 行情照样能更新；只是当天**新的**微信文章拿不到。已经写上去的微信不会被删掉。

---

## 「口令」是什么？

不是微信密码，不是公司邮箱，也不是 GitHub。

就是你**自己编的一串字**，当作 WeWe 的门锁。别人即使猜到网址，没有这串也看不了你的公众号列表。

例如编：`htbr2026`（请换成你自己的，不要用这个示例）。

记住它。后面填 3 次，必须一模一样：

1. 启动 WeWe 的那条命令里
2. 本机 `.env` 文件里（第 1 步末尾）
3. 网站云端的密钥里（第 3 步）

---

## 第 1 步：只在你电脑上跑 WeWe

### 1.1 安装 Docker Desktop

打开：https://www.docker.com/products/docker-desktop/

下载 Windows 版，安装完**重启电脑**。桌面出现鲸鱼图标，打开它，等到它显示 Running（正在运行）。

### 1.2 启动 WeWe

按键盘 `Win`，搜索 **PowerShell**，打开后**先 cd 到一个你找得到的文件夹**（比如桌面），再整段复制、回车（把口令换成你编的那串）：

```powershell
docker run -d --name wewe-rss -p 4000:4000 -e DATABASE_TYPE=sqlite -e AUTH_CODE=htbr2026 -e TZ=Asia/Shanghai -v ${PWD}/wewe-data:/app/data --restart unless-stopped cooderl/wewe-rss-sqlite:latest
```

第一次会下载几分钟，正常。

### 1.3 扫码登录微信读书

浏览器打开：http://127.0.0.1:4000

1. 点「账号管理」→「添加账号」
2. 用微信扫码，登录的是 **微信读书**（不是普通微信公众平台）
3. **不要勾**「24 小时后自动退出」

### 1.4 订阅 10 个公众号

点「公众号源」→「添加」。每个号随便找**一篇该号发的文章**，把链接贴进去。一次加一个，不要十分钟加完 10 个（容易被微信限制）。

要订这些号（后台显示的名字尽量一致）：

- 华夏基金
- 易方达微资讯
- 国泰基金
- 华泰柏瑞微理财
- 上交所发布
- 上交所投服
- 深交所
- 深交所投服
- 深交所上市通
- 深市基金

### 1.5 检查有没有通

浏览器打开下面这个地址（把 `htbr2026` 换成你的口令）：

```
http://127.0.0.1:4000/feeds/all.json?code=htbr2026&limit=10
```

若页面出现一堆英文/标题，就成功了。若是空白或报错，口令填错了，或 Docker 没在跑。

本机自动更新还会读项目根目录的 `.env`（这个文件不要提交到 Git）。用记事本新建，内容两行：

```
WEWE_RSS_URL=http://127.0.0.1:4000
WEWE_AUTH_CODE=htbr2026
```

**做到这里，你电脑上的微信列表已经可用。** 同事在网页上点更新要拿到微信，还需要第 2、3 步。

## 第 2 步：给云端开一扇固定的门（隧道）

这一步是为了让网上的更新按钮能访问到**你电脑上的** WeWe。需要：

- 一个 Cloudflare 账号（免费即可）
- 一个已经放到 Cloudflare 里的域名（没有域名会卡住，到这一步时喊我，我按你的情况写命令）

不要用每次一换的临时链接，网站会连不上。

装好 [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-apps/install-and-setup/installation/) 后，大意是：建一条叫 `wewe` 的长期隧道，指向 `http://127.0.0.1:4000`。最后你会得到一个固定地址，例如：

```
https://wewe-rss.你的域名
```

电脑要开着，Docker 和这条隧道也要开着。

---

## 第 3 步：把地址和口令告诉网站

在项目的 `worker` 文件夹里打开 PowerShell，执行（按提示粘贴，屏幕上不会回显，属正常）：

```powershell
wrangler secret put WEWE_RSS_URL
```

粘贴第 2 步那个 `https://...` 地址（末尾不要 `/`）。

```powershell
wrangler secret put WEWE_AUTH_CODE
```

粘贴和第 1 步相同的口令。

```powershell
wrangler deploy
```

`GITHUB_TOKEN` 若还没配，看旁边的 `DEPLOY.md`。

## 常见疑问

| 你可能想问 | 答案 |
|---|---|
| 口令忘了怎么办？ | 把容器删了用新口令再跑一次；三处都改成新的。 |
| 必须天天开电脑吗？ | 只有同事要点微信新文章时需要开。只更新行情/官网公告，电脑可以关。 |
| 第 4 步 feedId 要填吗？ | 不用。名字对得上就行。 |
| 口令能写进 Git 吗？ | 不能。 |
